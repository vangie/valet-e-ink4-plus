# Valet 随行 · E-Ink4 Plus 界面模拟

直接用浏览器打开 `index.html`。不连设备、模型和网关，语音、回答、配对和网络状态都是假数据。

页头有两个页签，切的是同一台假机器上的两套界面。读到哪一页、各项设置是共用的。

- **原始设计**：公开源码基线已同步到 2.0.82；2.0.81 的界面变化已结合公开源码复核。保留「自建」扩展；2.0.82 的应用商店、录音播放和宿主能力以固件源码为准，模拟器只模拟用户可见路径。
- **新设计**：Valet 随行。官方的斜切、黑白、整页翻没换；换的是助手在哪一层，以及设置怎么找。

## 新设计

- 首页第一屏是「提问」和「通话」两块，下面是助手连没连上、接着读、今天的待办。别的应用在第二屏，灰键翻。
- 通话只属于自己的助理：没选「自建」或还没配对时，首页、提问页、阅读卡片都不出现通话入口。首页仍是两块斜切，右边那块换成「接着读」（书名和进度），原来放接着读卡片的位置改成今天的待办列表，最多三条。
- 「这一页 / 随口问」决定谈什么，提问和通话只是怎么说。每一页的问答各自留着，随口问是单独一场。
- 正文像一页纸书：页眉只写章节（回次和回目各一行），页码在页脚正中。页面上不放按钮。点屏幕中间或短按 AI 唤醒键打开工具面板：问这一页、目录、书签、排版，点进去才是那一项。问过的页右上角有「注」。
- 问这一页、聊这一页不用切出去：问答在页面下方约 3/4 屏的悬窗里（上沿落在两行之间），书页上面留几行，墨水屏只刷这一块。按住说话、回答翻页、通话（静音 / 打断 / 挂断）都在悬窗里；侧键和点左右两侧照样翻书，悬窗跟着到那一页（每一页的问答各自留着）。点书页中间、菜单、或 AI 没在说时短按 AI 唤醒键收起；正文里长按 AI 唤醒键直接在悬窗里说。
- 什么时候切出去：悬窗里没有「新对话」「随口问」、拍照，也不翻以前的问答；回答超过两页时提示「全屏看全部」。点悬窗标题栏上的「全屏」进完整的助手页，同一场对话、通话不断；返回回到书页和悬窗。官方云拿不到这一页，照旧进完整页。
- 任何一屏长按 AI 唤醒键都能提问；待机时长按直接醒来提问。
- 设置按要做的事分六项：助手、网络、显示、阅读与字库、声音与蓝牙、设备。每一项直接写着现在的值，前光和音量在最上面；阅读设置包含官方 2.0.82 的晃动翻页开关和 1–5 级灵敏度。
- 第 2 页的「蟠」当作机内字库没有的字，画成方框，页脚提示缺字。设置 → 阅读与字库里可以假装装上扩展字库。
- 云服务选官方三项时：只有按住说话，没有通话，也不带正在读的那一页。

约束照真机：只用墨、纸和抖点，字号只用固件有的 20–50 px，每一屏都不滚动。

## 添加助理（设置 → 助手 → 自建 → 添加助理）

设备屏幕只显示地址、二维码和三步进度；真正的配置在手机或电脑的浏览器里做。设备屏幕上点「在电脑上打开配置页（模拟）」，页面右侧会弹出一个浏览器小窗，里面就是设备在局域网里提供的那个页面：`sim/valet_setup.html`（`main/valet_setup/valet_setup.html` 是指过来的链接，固件里打包的也是这一个文件，不另画一份）。

页面里的读写走 `setup.js` 里的假接口 `window.ValetSetupApi`，字段和设备的 `/api/assistants`（`main/valet_setup/server.cc`）一样，改的是模拟设备上的助理列表，所以「使用」「改名」「移除」「保存」之后设备屏幕跟着变。保存后先显示「请在助理那边批准」，4 秒后模拟批准、变成「已连接」。小窗右上角可以在电脑和手机宽度之间切换。

提示词写在设备页面里（只有中文），和固件一起改。

## 文件

| 文件 | 内容 |
|---|---|
| `state.js` | 假数据和共用状态 |
| `screens.js` `ai.js` | 原始设计的各屏 |
| `design.js` `design.css` | 新设计的各屏，以及页面外框的样式 |
| `nav.js` `live.js` `keys.js` `keys2.js` `touch.js` | 导航、通话、按键和触控，两套设计共用 |
| `setup.js` `setup.css` | 配置页的浏览器小窗、给页面的假设备接口、设备屏幕上的二维码图案 |
| `valet_setup.html` | 设备配置页源文件（`main/valet_setup/valet_setup.html` 链接到这里） |
| `sim.js` | 渲染、页签、右侧说明 |
| `images.js` | 内嵌的官方图标和关机画面 |

键盘：A 是 AI 唤醒，W / S 是加 / 减音量（正文里翻页），P 是电源，M 是菜单，← → 是两颗灰键。

样式类名约定：配置页和设备配对界面的状态类一律带 `is-` 前缀（`is-ok`、`is-cur`…）。旧界面的 `screen.css` 里有全局的 `.cur`、`.todo`、`.qr`，用裸名字会被它们改样式。

## 跟随上游

采用完整吸收官方能力、再叠加Valet功能的策略。固件源码、公开固件和原型依据分别显示，禁止只改版本号冒充源码已同步。两个Tab共用官方入口规则、VCOM回退和测试页。模拟器不模拟DMA/刷新时序，因此不能用于宣称底层修复完成。

版本与待验证项位于 `../tools/upstream/baseline.json`、`coverage.json`、`upstream.js`。每次合并都检查两套界面和对应物理按键；完整步骤见 [上游同步流程](../docs/upstream-sync.md)。
