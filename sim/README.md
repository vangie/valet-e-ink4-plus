# Valet 随行 · E-Ink4 Plus 界面模拟

直接用浏览器打开 `index.html`。不连设备、模型和网关，语音、回答、配对和网络状态都是假数据。

页头有两个页签，切的是同一台假机器上的两套界面。读到哪一页、各项设置是共用的。

- **原始设计**：公开源码基线已同步到 2.0.82；2.0.81 的界面变化已结合公开源码复核。保留「自建」扩展；2.0.82 的应用商店、录音播放和宿主能力以固件源码为准，模拟器只模拟用户可见路径。
- **新设计**：Valet 随行。官方的斜切、黑白、整页翻没换；换的是助手在哪一层，以及设置怎么找。

## 新设计

- 首页第一屏是「提问」和「通话」两块，下面是助手连没连上、接着读、今天的待办。别的应用在第二屏，灰键翻。
- 「这一页 / 随口问」决定谈什么，提问和通话只是怎么说。每一页的问答各自留着，随口问是单独一场。
- 正文上不放按钮。点屏幕中间或短按 AI 唤醒键出卡片，从那里问这一页、聊这一页。问过的页右上角有「注」。
- 任何一屏长按 AI 唤醒键都能提问；待机时长按直接醒来提问。
- 设置按要做的事分六项：助手、网络、显示、阅读与字库、声音与蓝牙、设备。每一项直接写着现在的值，前光和音量在最上面；阅读设置包含官方 2.0.82 的晃动翻页开关和 1–5 级灵敏度。
- 第 2 页的「蟠」当作机内字库没有的字，画成方框，页脚提示缺字。设置 → 阅读与字库里可以假装装上扩展字库。
- 云服务选官方三项时：只有按住说话，没有通话，也不带正在读的那一页。

约束照真机：只用墨、纸和抖点，字号只用固件有的 20–50 px，每一屏都不滚动。

## 添加助理（设置 → 助手 → 自建 → 添加助理）

设备屏幕只显示地址、二维码和三步进度；真正的配置在手机或电脑的浏览器里做。设备屏幕上点「在电脑上打开配置页（模拟）」，页面右侧会弹出一个浏览器小窗，这就是设备在局域网里提供的配置页。两边同步。

1. **让助理做好准备**：选 OpenClaw 或 Hermes，复制提示发给你平时聊天的助理。可以展开读全文，下面写着它会做什么、会先问你什么、不会做什么。
2. **粘贴助理的回复**：整段粘贴，地址、配对码和名称自动认出来。`ws://`、局域网或 `.local` 地址、地址和配对码对不上、配对码被截断，都会拦下并说明原因。
3. **保存到设备并连接**：设备依次测试写入、网关、签名握手、提问、通话、阅读上下文。通话没配置不算失败：助理照常添加，通话块灰掉，配好后在页面里重新测试。

提示词在 `prompts.js`，结构照 ai-passport 的 setup 提示：授权边界、分步检查并复用、验证后才签发配对码、固定格式回复。多出来的是阅读上下文、墨水屏回复的长度限制，以及设备可能走 4G（所以只收公网 `wss://`）。接入说明引用现有 `ai-passport-agent` 项目；Valet 固件的网关签名握手仍待实现，模拟流程不代表真实语音已接通。

页面底部虚线框里是只有模拟器才有的控制：填入演示回复，以及选下一次测试的结果（全部通过 / 通话未配置 / 配对码过期 / 连不上网关）。

## 文件

| 文件 | 内容 |
|---|---|
| `state.js` | 假数据和共用状态 |
| `screens.js` `ai.js` | 原始设计的各屏 |
| `design.js` `design.css` | 新设计的各屏，以及页面外框的样式 |
| `nav.js` `live.js` `keys.js` `keys2.js` `touch.js` | 导航、通话、按键和触控，两套设计共用 |
| `prompts.js` | 配置页复制给助理的提示词（OpenClaw / Hermes，中英文） |
| `setup.js` | 配置页的数据：识别助理的回复、演示回复、二维码图案 |
| `setup-ui.js` `setup.css` | 配置页的画法和交互（浏览器小窗） |
| `sim.js` | 渲染、页签、右侧说明 |
| `images.js` | 内嵌的官方图标和关机画面 |

键盘：A 是 AI 唤醒，W / S 是加 / 减音量（正文里翻页），P 是电源，M 是菜单，← → 是两颗灰键。

样式类名约定：配置页和设备配对界面的状态类一律带 `is-` 前缀（`is-ok`、`is-cur`…）。旧界面的 `screen.css` 里有全局的 `.cur`、`.todo`、`.qr`，用裸名字会被它们改样式。

## 跟随上游

采用完整吸收官方能力、再叠加Valet功能的策略。固件源码、公开固件和原型依据分别显示，禁止只改版本号冒充源码已同步。页头的国内/国际版独立于界面语言；两个Tab共用官方区域入口规则、VCOM回退和测试页。模拟器不模拟DMA/刷新时序，因此不能用于宣称底层修复完成。

版本与待验证项位于 `../tools/upstream/baseline.json`、`coverage.json`、`upstream.js`。每次合并都检查两套界面和对应物理按键；完整步骤见 [上游同步流程](../docs/upstream-sync.md)。
