# 随身 · E-Ink4 Plus 模拟器

这是 [valet-e-ink4-plus](https://github.com/vangie/valet-e-ink4-plus) 里用来讨论产品的假界面。用浏览器打开 `index.html` 就能点。不编译固件，不连设备，不连网关。

壳子和按键按官方产品图、固件关机画面 `bg_shutdown_zh.png` 对过：

- 右侧三颗键帽、四个功能。上面短键是 AI 唤醒，中间长条上半加音量、下半减音量，下面短键是电源。
- 屏下从左到右：菜单、返回 / 上一页、前进 / 下一页。

按键行为按官方固件 2.0.80。正文里短按 AI 唤醒弹出阅读卡片，长按才进百问。音量键只在正文里翻页。官方百问拿不到正在读的这一页；只有选中「我的 AI」时才带上这一页。

电脑键盘：A 是 AI 唤醒，W / S 是加 / 减音量，P 是电源，M 是菜单，左右方向键是两颗灰键。
